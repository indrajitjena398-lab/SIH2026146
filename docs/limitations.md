# System Limitations & Forensic Boundaries

1. **Investigative Decision Support, Not Legal Proof**: ML scores and risk indicators are prioritized investigation leads, not conclusive legal evidence of criminal activity.
2. **Synthetic Network Telemetry**: Public Bitcoin datasets do not contain intercepted P2P IP telemetry. Network data is synthetic and explicitly labeled as such.
3. **Pseudonymity vs Identity**: Bitcoin addresses are cryptographic public keys and do not directly identify real-world physical identities without KYC/subpoena corroboration.
4. **Unlabeled Class Ambiguity**: "Unknown" transactions in public datasets cannot be assumed to be licit; they simply lack ground-truth attribution.
5. **GeoIP Approximation**: IP geolocation represents routing infrastructure locations, which may be obscured by VPNs, proxies, or Tor relays.
